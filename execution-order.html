WHY THIS ORDER?

Runtime stages

01
Call stack

Runs the current synchronous job to completion. Nested function calls create stack frames and return in last-in, first-out order.

02
Microtask queue

After the stack is empty, Promise reactions and queueMicrotask() callbacks run. Newly queued microtasks are also drained before the next task.

03
Task queue

Timer and event callbacks run as later tasks. A zero-millisecond timeout does not run before the current job and microtasks finish.

04
Rendering opportunity

After task and microtask processing, the browser may update rendering before the next event-loop iteration.

How `this` is determined
